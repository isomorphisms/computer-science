# Planner

Compose primitive operations and known algorithms into candidate implementations that satisfy explicit semantic and architectural constraints.

Treat the alternatives as a decision tree. Use proofs, contracts, asymptotic calculations, and other analytic estimates first to reject impossible or clearly inferior branches. Reuse stored observations where they apply. Run experiments only where calculation and existing evidence leave a consequential uncertainty.

When a real run occurs, preserve its decision path and results so the search system learns from work it has already done.
