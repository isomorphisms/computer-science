# SURFER example

Starting question:

Given a polynomial zero set, Android touch input, a concrete CPU/GPU target, and an interactive-frame requirement, construct viable rendering architectures instead of requiring the programmer to choose the architecture manually.

Use mathematical analysis first where it is decisive: asymptotic costs, operation counts, memory use, bandwidth, numerical properties, and results available from papers. Then use cached observations from real machines where the abstract analysis does not determine the practical choice. New executions add observations rather than disappearing as one-off benchmark results.

This example should eventually connect the primitive catalog, algorithm catalog, calculations, observations, and planner in one reproducible problem.
