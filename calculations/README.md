# Calculations

Store reusable calculations that can guide architecture search before anything is benchmarked.

Examples include Big-O time and space bounds, operation counts, memory-footprint estimates, bandwidth requirements, numerical-error bounds, crossover estimates, and calculations derived from papers.

A calculation should state its assumptions and source. The point is to eliminate or rank large parts of the design tree mathematically when possible, rather than measuring every candidate just because it can be measured.
